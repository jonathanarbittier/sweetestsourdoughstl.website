# Sweetest Sourdough STL website

Next.js site for Sweets & Sourdough.

## Development

- `npm install`
- `npm run dev`
- `npm run lint` (TypeScript check)
- `npm run build`

## Images

The site uses optimized assets in `public/images/`. The photographer originals stay in the ignored `source-photos/` folder and must not be committed or served. Keep new production photos sized for their displayed use and store the bakery images in `public/images/sweetest-sourdough/`.

The sources for the Around the Cart images are recorded in `docs/instagram-sources.md`.
